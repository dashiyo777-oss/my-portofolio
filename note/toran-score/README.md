# TORAN 国会活動量スコア — 採点仕様

`score.py` が何をどう計算しているかを、記事の第4章で要求している
**母集団・期間・出典・方法・限界** の5点セットの形で書き出したものです。
この5点が書けない数字は記事に載せません。

```
python3 audit.py 名簿.csv --clean きれいな名簿.csv   # ① 先に名簿を検証・修復する
python3 score.py きれいな名簿.csv -o 採点済み.csv    # ② それから採点する
```

**順番が大事です。** 名簿を検証せずに採点すると、実在しない行に点が付きます。
実際、最初のCSVには同一人物の重複が43行ありました（下の「6. 名簿の検証」）。

---

## 0. このスコアが測っていないもの（先に読んでください）

このスコアは **実績でも、優秀さでも、政策の良し悪しでもありません。**
国会でどれだけ手を動かしたかという **活動量** だけを、相対順位に直したものです。

- 発言が多いことは、内容が良いことを意味しません
- 議員立法を多く出すことは、それが通ったことを意味しません
- スコアが低いことは、仕事をしていないことを意味しません

列名を「総合スコア」ではなく **「活動量スコア」** にしているのは、
名前が測っている中身を超えないようにするためです。

## 1. 母集団

現職の国会議員 **712人**（衆議院465人・参議院247人）。
`audit.py --clean` で重複43行を統合したあとの数字です。

| 区分 | 人数 | 定数 | 扱い |
|---|---:|---:|---|
| 衆議院 | 465 | 465 | 採点。小選挙区289＋比例176も定数どおり |
| 参議院 | 247 | 248 | 採点。**1人足りません**（比例100は定数どおり、選挙区が147/148）|
| 首長 | 47 | — | **対象外**。国会での活動量を測る指標なので比較できません |
| 候補 | 7 | — | **対象外**。議席を持っていません |
| 元議員 | 4 | — | **対象外**。在職期間が母集団と揃いません |

修復後は **712人全員の採点が成立** します（未取得0人）。
修復前は「参議院28人が素材未取得」でしたが、うち25人は実在しない重複行、
残る3人は活動量が本名表記の行に載っていただけでした。

参議院が1人足りない件は未解決です。欠員か取りこぼしかは、名簿の一次資料に
当たらないと判別できません（下の「8. 確かめられていないこと」）。

## 2. 期間

入力CSVの列定義をそのまま使っています。

- 発言数: 2021年11月 〜 2026年7月
- 質問主意書: 第207回 〜 第221回国会
- 議員立法（発議・賛成者）: 期間の記載なし ← **要確認**

## 3. 出典

入力CSV（`TORAN_..._20260821.csv`）。この4列がどの一次資料から
どう集計されたかは **CSV側に記載がなく、未検証です。**

本来の一次資料は次の3つですが、この作業環境からは到達できませんでした
（詳細は「8. 確かめられていないこと」）。

- 国会会議録検索システム `kokkai.ndl.go.jp`（発言数）
- 衆議院 `www.shugiin.go.jp`（質問主意書・議案経過情報）
- 参議院 `www.sangiin.go.jp`（同上）

## 4. 方法

### 4-1. 使う列と重み

| 列 | 重み | 理由 |
|---|---:|---|
| 発言数 | 30% | 量が最も大きく、活動の基礎 |
| 質問主意書 | 20% | 提出に手間がかかり、意思が読める |
| 議員立法（発議） | 30% | 発議者になるのは4つの中で最も重い |
| 議員立法（賛成者） | 20% | 署名のみ。発議より軽く見る |

重みは `score.py` 冒頭の `WEIGHTS` に定数として置いてあります。
**変えたら、この表と下の更新履歴を必ず直してください。**
数字を動かした痕跡が残らない採点は、再現できる採点ではありません。

### 4-2. 生の件数ではなく院内パーセンタイルを使う

発言数は 0〜9,540 と分布が極端に歪んでおり、生の数字を足すと
発言数だけでスコアが決まってしまいます。そこで各列を
**その院の中での順位（0〜100）** に直してから加重します。同値は同順位です。

院ごとに分けるのは、衆参で発言機会の総量が違うためです。
スコアと同時に `院内順位` 列（例: `12/465`）を必ず出力します。

### 4-3. その院で使えない列は外して重みを再正規化する

「議員立法（賛成者）」は参議院262人中1人しか値がありません。
そのまま使うと参議院の全員に同じ定数が乗るだけなので、
値を持つ人が5%未満（`MIN_COVERAGE`）の列はその院では未収集とみなし、
採点から外して残りの重みを合計1.0に戻します。
外した列は実行時に画面へ出し、出力CSVには `未収集` と書きます。

### 4-4. 0 と 空欄を区別する

- `0` は **「0という記録」**。採点に使います
- 空欄は **未取得**。スコアを空にし、どの列が欠けたか理由を書きます

### 4-5. ランクは絶対評価ではない

A / A- / B+ / B / B- / C+ / C は、上位5% / 15% / 30% / 50% / 70% / 85% で
切った **相対評価** です。合格ラインではありません。

## 5. 限界（記事に載せるなら、この4つは必ず併記する）

### 5-1. 与野党の立場を測ってしまう ← 最も重い

集計すると野党の平均が高く、与党の平均が低く出ます（712人・修復後）。

| 政党 | n | 平均 |
|---|---:|---:|
| 日本共産党 | 11 | 72.6 |
| （要確認） | 48 | 71.0 |
| 国民民主党 | 53 | 62.5 |
| 日本維新の会 | 55 | 62.3 |
| 立憲民主党 | 40 | 61.2 |
| 公明党 | 21 | 51.2 |
| 自民党 | 417 | 43.4 |
| 参政党 | 30 | 40.3 |

これは努力の差ではなく **役割の差** です。野党議員は質疑で政府をただし、
質問主意書を出す。与党の当選回数が浅い議員が本会議で発言する機会は
構造的に少ない。**この指標で政党を比べると、努力ではなく与野党の別を
測ることになります。**

政党別の平均を記事に出すことは、現時点では勧められません。

**この指標では、非自民の衆議院議員149人のうち発言数0が「1人もいません」。**
自民党は316人中35人（11.1%）が0です。1〜10回の層も衆議院44人中39人が自民党でした。

能力差ではありません。**質疑に立つ側と答弁する側の役割差**が、そのまま数字に出ています。
連続的に偏っている（0だけでなく1〜10回の層も同じ傾向）ので、収集漏れではなく構造です。
これは政党比較をしてはいけないことの、いちばん強い証拠です。

### 5-2. 在職年数を補正できない

期間は2021年11月からの約4年9か月ですが、CSVには
**当選回数も初当選年もありません。** 2026年2月の総選挙で初当選した議員と、
期間の全部を在職した議員が、同じ物差しで並びます。
補正する材料が手元にないので、**これは直せません。**

### 5-3. 役職が発言数を押し上げる

大臣・委員長は答弁する側なので発言数が跳ね上がります。
発言数は「活発さ」ではなく「役職」を測っている部分があります。

### 5-4. 政党欄に48人の「（要確認）」がある

衆議院48人の政党が未確定です（公明党・立憲民主党の議員が混在）。
**この48人が埋まるまで、政党別の集計はどの形でも確定しません。**

## 6. 名簿の検証（`audit.py`）

採点の前に、外部に問い合わせずCSVの中だけで確かめられることを全部やります。
制度上の定数と突き合わせるので、一次資料に当たれない環境でもここまでは検証できます。

### 6-1. いちばん大きな問題：同一人物が43行ぶん重複していた

参議院が **290人** で、定数248より42人多い。原因は氏名が `[ ]` で囲まれた43行でした。

これは **通称で活動している議員の、戸籍名の行** です。
参議院の名簿は本名を角括弧で併記するため、取り込みのときに別人として1行増えていました。

| 残す行（通称） | 消す行（本名） |
|---|---|
| ラサール石井 | [石井 朗夫] |
| 蓮舫 | [齊藤 蓮舫] |
| いんどう 周作 | [犬童 周作] |
| 福島 みずほ | [福島 瑞穂] |
| 塩村 あやか | [塩村 文夏] |

同一人物だと判断した根拠は4つです。

1. **43行すべてが、非`[ ]`の参議院行の直後にある**（IDが1つ違い）
2. 43行を除くと参議院は **247人**、比例は **ちょうど100人** で定数と一致する
3. 43行はすべて政党が「無所属」・選挙区が空。名簿としての属性を持っていない
4. 34/43は姓か名が機械的に一致。残り9件も読みで一致（芙美代／ふみよ、英子／はなこ 等）

福島みずほ議員は通称行・本名行ともに発言数1420で、**同じ発言が二重に数えられて
いた**ことがそのまま出ています。

### 6-2. 削除ではなく統合する

3人（いんどう周作・上野ほたる・江原くみ子）は、活動量が本名の行にしか
載っていませんでした。単に消すとデータが消えます。

`--clean` は通称の行を残し、空いている列だけ本名の行から埋めます。
両方に非ゼロの値があって食い違う2件（かまやち敏 19/18、小林さやか 157/61）は
大きいほうを採り、画面に出します。**足し合わせません** ——
同じ発言の二重計上なのか表記ごとに分かれているのか、一次資料なしでは判別できないからです。

### 6-3. 修復しても残る不整合

`audit.py` が報告し、**まだ直っていない** ものです。

| 内容 | 件数 | 例 |
|---|---:|---|
| 参議院が定数より1人少ない | 1 | 欠員か取りこぼしか不明 |
| 院と役職が食い違う | 4 | 伊藤達也・岩屋毅・内山こう・梅村聡（院=衆議院／役職=参議院議員）|
| 政党と役職が食い違う | 1 | 岩谷良平（政党=日本維新の会／役職=自由民主党政務調査会長）|
| 政党が「（要確認）」 | 48 | 全員衆議院。公明党・立憲民主党の議員が混在 |
| 同じ氏名が複数行 | 2 | 鬼木誠（衆・自民／参・立憲）、飯泉嘉門（衆・国民／徳島県知事）※同姓同名の可能性 |
| 役職が「（要確認）」 | 738 | 先頭75行以外すべて |

役職・ランクが入っているのは **CSVの先頭75行だけ** です。
五十音順の「あ行〜う行」で作業が止まっており、これは政治的な傾向ではなく
作業順の産物です。

## 7. 既存の「総合スコア」列との関係

CSVには66人ぶんの `総合スコア`（55〜82）が入っていますが、
**同じCSVの4列からは復元できません。**

- 4列との相関は最大 r=+0.31、単純合計でも r=+0.31
- 4列すべてを使った線形回帰でも残差が平均5.8点（スコア幅は27点）
- 発言数2回の議員が75点、発言数805回の議員が55点

活動量スコアと突き合わせると **±5点以内に収まるのは66人中8人** で、
平均13.6点ずれます。両者は別の物差しです。

既存の66点が何を測っているのかが書き出せない以上、
**新旧を混ぜたランキングは作れません。** どちらかに寄せてください。

## 7-2. 数値の妥当性（一次資料なしでどこまで疑えたか）

`audit.py` は数字の形からも異常を探します。結果は次のとおりです。

| 検査 | 結果 |
|---|---|
| 列どうしの論理矛盾（発言0なのに主意書提出など）| **0件** |
| 発言数の最大値 | 岸田文雄 9,540回＝**5.50回/日**。上位10人は全員が首相・大臣経験者で、答弁側なら説明がつく |
| 発言数0 | 40人。うち**37人が自民党**（8.9%）。20人以上いて0人なのは公明党・参政党ほか |
| 4列すべて0（在職の痕跡なし）| 26人。比例に48.6%と偏る（全体は37.8%）ので新人の可能性が高い |

**発言数0の40人は、収集漏れではなく構造の反映と読むのが整合的です。** 収集漏れなら
政党と無関係に散らばるはずですが、実際は自民党に集中し、しかも1〜10回の層まで
連続して同じ偏りが出ています。ただし当選回数の列がないため、**確定はできません。**

つまり数値は「内部的には筋が通っている」ところまでは確認できました。
**原典と一致するかは別問題で、そちらは未検証のままです。**

## 8. 確かめられていないこと（重要）

**この作業では、一次資料に一度も当たれていません。**
検証したのはすべて「CSVの中だけで分かること」です。

作業環境の外向き通信が組織のエグレスポリシーで遮断されており、
次のホストはいずれも 403 で拒否されました。

| ホスト | 用途 | 結果 |
|---|---|---|
| `kokkai.ndl.go.jp` | 国会会議録検索システム（発言数の原典）| 403 拒否 |
| `www.shugiin.go.jp` | 衆議院（質問主意書・議案経過情報）| 403 拒否 |
| `www.sangiin.go.jp` | 参議院（同上・議員名簿）| 403 拒否 |

したがって、**次のことは未検証のままです。**

- 発言数・質問主意書・議員立法の件数が、原典と一致するか
- 「発言」の定義（本会議のみか、委員会を含むか、答弁を含むか）
- 参議院が1人足りない理由が、欠員なのか取りこぼしなのか
- 政党「（要確認）」48人の正しい所属
- 院と役職が食い違う5件の、どちらが正しいのか
- 同姓同名2件が、別人なのか重複登録なのか

数字を記事に出す前に、通信できる環境でここを埋めてください。
国会会議録検索システムには公開APIがあり、議員ごとの発言件数は
`https://kokkai.ndl.go.jp/api/speech?speaker=<氏名>&from=<日付>&until=<日付>`
の `numberOfRecords` で機械的に取り直せます。
