## Day 1〜14｜Threads 導線投稿（1日1〜2本・各10分）

ルール（`SKILL.md` §7）：**感嘆符なし／数字は半角／リンクは本文でなく1コメ目／稼ぐ系ワードは使わない。**
下の文面はそのまま使える形で書いてある。順番も設計済み（信頼→手段→目的→問題の繰り返し。売り込みは8:2の「2」だけ）。

> 文面の数字はすべて2026-08-24取得の実データ。**変えないこと。**

### 【投稿1】公開当日（信頼の教育＋告知）

```
国会議員707人の発言数を、公的資料から自分で数えました。

上位10%の70人が、全発言の39.4%を占めていました。
下位50%の353人は、あわせて10.6%です。

数えて分かったのは「サボっている」という話ではなく、
発言の機会そのものが偏って配られている、という構造でした。

どうやって数えたか、手順を全部note に書きました。
```
1コメ目：記事URL＋「無料部分だけでも、使える資料の一覧になっています」

### 【投稿2】Day 1（手段の教育）

```
国会会議録検索システムは、1947年からの全発言が無料で引けます。

議員名で検索すると、その人が国会で実際に喋ったことが
一言残らず出てきます。

政治を調べる道具として最強なのに、
たぶん一番使われていません。
```
リンクなし。コメントが付いたら会議録システムのURLを返す。

### 【投稿3】Day 2（問題の教育）

```
発言回数が少ない議員を「サボり」と読むのは、たいてい間違いです。

707人分を数えて分かったのですが、
発言数の上位20人は、多くが大臣か大臣経験者でした。

大臣は答弁する側なので、発言は自動的に積み上がります。
つまりあの数字は、活発さではなく役職を測っていることがある。

数字は、何を測っているかを確かめてから使うものだと思います。
```

### 【投稿4】Day 3（信頼の教育・失敗談）

```
707人分を集計していて、私自身が一度だまされかけました。

「発言0回の議員が40人いて、うち37人が自民党」
というデータが出てきたんです。構造的な発見だと思いました。

原典に当たり直したら、40人のうち38人は0ではありませんでした。
元データの集計時点が古かっただけでした。

データの中だけ見ていると、辻褄の合った嘘に出会います。
```

### 【投稿5】Day 4（手段の教育）

```
元総理の国会発言、5年間で2回という人がいます。

嘘みたいですが、国会会議録検索システムで誰でも確認できます。
1件は議長への祝辞でした。

有名かどうかと、記録に残っているかは、別の数字です。
```

### 【投稿6】Day 6（目的の教育）

```
選挙のとき、私は印象で選んでいました。

テレビでよく見る、発信が力強い、感じがいい。
でもそのどれも、記録とは別のものでした。

707人分を数えたのは、誰かを落とすためではなく、
印象で決めるのを自分がやめるためでした。
```

### 【投稿7】Day 8（手段の教育）

```
政治資金収支報告書で見るべきは、支出ではなく収入です。

何に使ったかは話題になりやすい。
でも構造を語るのは、誰から入ったかのほうです。

収入の構成比と、上位の寄付者。見るのはこの2つだけでいい。
```

### 【投稿8】Day 10（信頼の教育＋告知・2回目）

```
同姓同名の別人を、5人見つけました。

議員707人の発言数を集計したとき、
名簿の読みと、会議録の読みを突き合わせたら、
5人だけ別人の発言を数えていたことが分かりました。

このチェックを飛ばすと、他人の発言数で議員を語ることになります。
検証の手順は、noteに全部書いてあります。
```
1コメ目：記事URL

### 【投稿9】Day 12（問題の教育）

```
「関係者によると」で始まる政治記事を、私は読まなくなりました。

出典が書いていない数字は、確かめようがないからです。

かわりに、出典と取得日が書いてある文章だけを信じることにしました。
自分が書くときも、同じにしています。
```

### 【投稿10】Day 14（目的の教育・締め）

```
政治の話は、記録で語ると喧嘩になりません。

意見と意見がぶつかると感情になりますが、
「会議録にはこうあります」は、確かめれば終わるからです。

印象ではなく記録で話す人が増えるといいなと思って、
数えたものを公開しています。
```
