## 0. 「売れるnote」の前提 ― 何を売るのか

政治・経済ジャンルで**意見は売れない**。無料でいくらでも手に入るからだ。売れるのは次の3つに限られる。

| 売れるもの | 理由 | 賞味期限 |
|---|---|---|
| **① 再現可能な手順（How）** | 読者が自分でできるようになる＝対価が明確 | 長い（エバーグリーン） |
| **② 自前で集めた一次データ** | どこにも落ちていない＝代替不能 | 中（更新で延命） |
| **③ 翻訳（制度 → 自分の生活）** | 「で、私の手取りはどうなる」に答える | 中〜長 |

意見・論評は**無料記事**でよい。無料記事は信頼の貯金であり、有料noteの入り口である。
この順序を逆にすると、「有料なのにポジショントークだった」と評価され、一度で終わる。

### 価格の根拠

少フォロワー期の適正帯は 100〜2,980円（`.claude/skills/threads-monetize/SKILL.md` §6）。
780円は「メンバーシップ（月300円）2.6か月分」に見える価格で、**メンバーシップへの誘導が働く**位置。
単品で買った人にも損はなく、迷った人は月額に流れる。値付けの主目的は売上ではなく**導線**である。

### 公開前に必ずやること

3. 出典リンクを1つずつ開いて開通確認
4. 「編集メモ」ブロックを削除してから貼り付ける

## 2. 導線（Threads → note）

教育投稿の4類型（目的・信頼・手段・問題）を、この記事に合わせて割り当てる。
**説教しない。投稿の内容から間接的に感じ取ってもらう。**

| 類型 | 投稿の中身 | 例（1行目） |
|---|---|---|
| **目的の教育** | なぜ印象で選ぶのが損なのか | 露出量と、国会での発言量は、別の数字です |
| **信頼の教育** | 自分で数えた事実を出す | 813人分を、公的資料から手で数えました |
| **手段の教育** | 無料ソースを1つずつ小出し | 国会会議録検索システムは、1947年からの全発言が無料で引けます |
| **問題の教育** | よくある調べ方の落とし穴 | 発言回数が少ない議員を「サボり」と読むのは、たいてい間違いです |

運用ルール（`SKILL.md` §7）：感嘆符なし／数字は半角／**リンクは本文に貼らず1コメ目**。

### 販売の型

**エバーグリーン**（販売日を決めず、じわじわ売り続ける）を採用。
理由：この記事は時事に依存しないため、ローンチの瞬間風速より、**手段の教育投稿を積み続けるほうが効く**。
販売後は口コミ・追記・固定投稿で延命する（追記のたびに更新履歴を残す）。

第1弾を「入口」として、**手順 → 各論 → 応用** の順に降ろしていく設計。
すべて「1記事1テーマ」「読了後に自分でできる」を満たすものだけを並べている。

| 02 | 政治資金収支報告書の読み方だけを、1本にまとめました | 手順 | 580円 |

| 06 | 政府統計の「定義変更」を見抜く（数字が急に動いた年の読み方） | 手順 | 780円 |

> **束ね方**：02〜04が溜まったら「一次情報で政治を読む・基礎編」としてマガジン化。
> マガジンは単品合計より安く、メンバーシップより高く置くと、月額への圧力になる。

### 書かないと決めているもの

- 政党・個人の応援／落選運動
- 出典のない「関係者によると」
- 速報性で勝負するニュース解説（一次情報の強みが出ず、賞味期限も短い）
- 収益目的のアフィリエイト（このブランドでは一切混ぜない）

## 4. 記事の共通フォーマット

1. **タイトルは最後に決めない、最初に決める。** 記事のコアを射抜く1本の刃として先に立てる
2. **起でキーワードを1つ置き、結で回収する**（本作は「印象／記録」）
3. **数字は核心に1〜2個。**乱れ打ちしない
4. **断定を避ける。**「〜の疑いがある」「記録上は〜と読める」
5. **限界を書く。**数えられていないものを明示した記事だけが信用される
6. **更新履歴を残す。**エバーグリーン販売は、更新が生命線
