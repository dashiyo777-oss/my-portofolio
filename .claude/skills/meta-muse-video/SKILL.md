# Meta Muse 動画制作スキル

> 出典：YouTube「【Meta Muse動画生成】プロンプトのみで実写風・アニメ風動画を作る方法！AIエージェントにワークフローを任せて自動生成する方法を解説」（AI共創イノベーション／ワンダー佐藤、20分56秒）の文字起こしを要約し、手順に落とし込んだもの。
> 動画の内容（事実）と、このスキルで補ったもの（★補足）を分けて書く。Museの機能や制限は変わりやすいので、使う前に実機で確かめる。

---

## 0. 考え方：生成と組み立ての分業

- **素材はAIに生成させ、組み立てはコードでやる。** これが品質と速さを両立させる土台（動画内のAIナレーションの結論）。
- Museの中には**クラウド上の仮想PC**があり、Python で動画のトリミング、音声の削除、連結、ズーム、テロップ合成ができる。それを**チャットのプロンプトだけ**で頼める。
- 動画クリップは**1本10秒まで、延長はできない**。だから10秒の素材を何本も作ってつなぐ（6本で1分、20本で3分強）。
- 映像に日本語をしゃべらせると間違えやすい。**音声は別に作る（ポッドキャスト機能や読み上げ音声）と日本語が正確になる。**
- 実例：59秒の実写風の解説動画（素材6本）、同じ内容のアニメ版、3分の解説動画（動画とイラストとコードの動きを組み合わせたもの）。

使いどころ：メインチャンネルの主力作品より、**サブチャンネル、解説動画、リール、ショート**向き（動画作者の評価）。

---

## 1. 8つの工程

| # | 工程 | やること | 要点 |
|---|------|----------|------|
| 1 | 台本 | **セクション**と**セリフ行**の2階層で書く | セリフは短く区切る。**1行が台本から合成までの最小単位**。目安は1分で約10行、3分で約30行。ここを一番しっかり作り込む |
| 2 | 音声 | 映像より先に音声を作る（**音声先行**） | 行ごとに読み上げ音声を作り、長さを1行ずつ**実測**する。極端にゆっくり読まれた行は、言い換えて作り直す |
| 3 | 文字起こし | 実測から**タイムスタンプ付きの文字起こし**を作る | これは音声認識ではなく、**台本と実測時刻の対応表**。だからテロップと音声がずれない |
| 4 | 分割計画 | 文字起こしを、1本で生成できる長さの区間に分ける | 行を足していき、上限（10秒）を超える手前で切る。本数の目安は総尺÷10。区間ごとにどんな場面にするかを決める。**この計画はAIに考えさせる** |
| 5 | 素材生成 | 区間ごとに動画クリップやイラストを作る | プロンプトは「**共通のスタイル文**＋**キャラクター描写**＋**場面の内容**」で組む。キャラクター描写は毎回同じ文にする。動画とイラストを混ぜると表現の幅が広がる |
| 6 | 無音化 | 生成した素材の音声を外す | 動画を生成すると勝手に音（声やBGM）が入るので、必ず消す |
| 7 | 連結と合成 | 長さをそろえ、無音のまま隙間なくつなぐ | 区間の境界は**セリフとセリフの間のちょうど真ん中**で決める。その上に実測どおりにナレーションを重ねる。タイトル、セクションタイトル、テロップはコードで正確な位置に合成する。テロップは文字起こしから作る |
| 8 | 検証と仕上げ | 尺と音量を確かめ、画面を抜き出して目で見る | おかしい場面は**その素材だけ作り直して組み直す**（全部は作り直さない）。うまくいったらスキルにする |

**一番のコツ：ナレーションと文字（テロップ）のタイミングを合わせること。** ここさえ押さえれば、プロンプトの書き方は自由でよい。

★補足：工程5の「プロンプトは3層構造」は、動画の中で画面に映るスライドで説明されていたが、字幕に中身が出てこない。このスキルでは、AIナレーションの説明（共通スタイル文、毎回同じキャラクター描写、場面の内容）をその3層として扱う。

## 2. 画面の型（動画の実例）

- 上：**タイトル**（大きな文字）／**セクションタイトル**
- 中央：生成した映像やイラスト（背景にキャラクター）。ズームや最後の静止などの動きはコードで付ける
- 下：**テロップ**（ナレーションの文字起こし）
- 音声：ポッドキャスト（2人が交互に話す形）。1人で読み上げたいときは、Museの仮想PCに**無料の読み上げ音声**を入れて使う方法もある

アニメ風にするときも、この型はそのまま。**変わるのは背景のキャラクターとスタイル文だけ。**

## 3. Museに渡すプロンプトのテンプレート

動画作者によると、最初のプロンプトは「やり方を順番に書くだけ」の短いものでよい。以下は、文字起こしの内容を手順に起こしたもの（★補足：文面はこのスキルで作った。動画に映っていたプロンプトの原文ではない）。

### 3-1. 一括指示（最初の1本）

```
次の手順で、約【60】秒の解説動画を作ってください。テーマは【テーマ】です。

1. 台本：セクションとセリフ行の2階層で書く。セリフは1行を短くし、1分で約10行にする。
2. 音声：台本をポッドキャストの音声にする（または行ごとに読み上げ音声を作る）。行ごとの長さを実測する。極端に遅い行は言い換えて作り直す。
3. 文字起こし：実測した時刻と台本を対応させた、タイムスタンプ付きの文字起こしを作る。
4. 分割計画：文字起こしを10秒以内の区間に分ける（上限を超える手前で切る）。区間ごとの場面を決めて、表で見せる。
5. 素材：区間ごとに10秒の動画を生成する。プロンプトは「共通スタイル文＋キャラクター描写（毎回同じ文）＋場面の内容」で作る。
   共通スタイル文：【例：実写風、明るいオフィス、自然光、シネマティック】
   キャラクター描写：【例：30代の日本人女性、黒髪ボブ、白いシャツ】
6. 無音化：生成した動画の音声をすべて消す。
7. 合成：動画を無音のまま隙間なくつなぎ（境界はセリフの間の真ん中）、ナレーション音声を実測どおりに重ねる。上にタイトル（大きな文字）とセクションタイトル、下にテロップ（文字起こし）をコードで合成する。
8. 検証：尺と音量を確かめ、画面を何枚か抜き出して見せる。

書き出し先：【Googleドライブの〇〇フォルダ】に、完成動画と素材をまとめて保存する。
```

### 3-2. 部分修正

```
【セクション3】の映像がおかしいので、その素材だけ作り直して組み直してください。ほかはそのままにしてください。
```
スクショを添えて「この場面だけ変えて」と頼んでもよい。

### 3-3. スキル化（うまくいったら）

```
今回の動画の作り方を、次回から同じ手順で作れるスキルにしてください。8つの工程、画面の型、スタイル文とキャラクター描写を含めて、Googleドライブの【〇〇】に保存してください。
```
これで**次回からプロンプトは「テーマ」と「長さ」だけ**でよくなる。

### 3-4. 作り分け（スキルを使って）

```
さっきのスキルで、同じ内容をアニメ風にしてください。キャラクターは【この2人】にしてください。
```
```
さっきのスキルで、【テーマ】の3分の動画を作ってください。必要な素材の本数は計算して決めてください。
```

## 4. 進め方と注意

1. **まずは普通の、オーソドックスな動画を1本作って様子を見る。** 応用（スタイル変更、イラストやコードの動きを混ぜる、長尺化）はその後にする。
2. **長くするときは**、総尺と素材の本数（総尺÷10）をAIに理解させる。3分でも10分でも作れる。
3. **書き出し先は必ず指定する。** 指定しないとクラウドの中に残って、どこに行ったか分からなくなる。長く残す素材は、**素材ごとGoogleドライブに保存**する。
4. 生成映像は**ときどき崩れる**。工程8の目視チェックを省かない。
5. Museはスライドも作れる（「10枚作って」と頼むと10枚。PDF化、PowerPoint化もできる）。動画の構成案をスライドで先に作るのも手。

## 5. このプロジェクトでの使い方（★補足）

- **公開前の確認**：ナレーションや台本は `knowledge/professional-writing-blueprint.md` の倫理に従う。嘘を売らず、一次情報で確かめる。AIで生成した実写風の人物を、実在の人物や体験談のように見せない。
- **楽曲配信の説明文**に動画の紹介文を流用するときは、CLAUDE.md の表記ルールに従い、ダッシュやハイフン類を使わない。
- 歌詞MV（`*-lyric-mv.mp4`）やプロモ動画（`sae-hana-awase-promo.mp4` など）の制作でも、「音声先行→タイムスタンプ→10秒単位の素材→無音で連結→音声とテロップを合成」という流れはそのまま使える。曲の場合は、ナレーション音声の代わりに楽曲ファイルを物差しにする。
