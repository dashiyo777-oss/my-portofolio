# kanpo-archive（非公開）

官報発行サイト（https://www.kanpo.go.jp/ ・内閣府）は、発行から原則90日間だけ官報全体をPDFで公開し、
90日経過後はプライバシーへの配慮が必要な記事（破産・相続財産・行旅死亡人など）を閲覧できなくします。
このリポジトリは、それが消える前に一括PDFを保管するための **非公開** アーカイブです。

- `.github/workflows/kanpo-archive.yml` … 毎日 06:17 JST に自動実行（Actions タブから手動実行も可）
- `fetch_kanpo.py` … 取得スクリプト（保管済みの日付は再ダウンロードしない）
- **Releases** … `kanpo-YYYYMMDD` ごとに、その日の本紙・号外・政府調達・特別号外の一括PDF
- `toc/YYYYMMDD.json` … 各号の目次（区分・記事タイトル・ページ）

## 取り扱いの注意
- 個人情報を含むため、**このリポジトリは公開しない**・PDFを再配布しない。
- 記事執筆に使うのは統計・傾向（件数の推移など）や公的機関の告示であり、
  個人を特定できる形で転載しない（いわゆる「破産者マップ」問題の二の舞にしない）。
