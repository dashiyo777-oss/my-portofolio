🧵 Threads キーワード探索

キーワードにヒットした公開投稿を集計し、
そのテーマで露出が多い順にアカウントを並べます。

ハブへ戻る ｜ カウント一覧 ｜ 楽天アフィリ投稿アシスタント

この道具の正直な限界（公式API準拠）：
Threads公式APIは「他人のフォロワー数・投稿の閲覧数」を返しません。そのためフォロワー数順の並べ替えはできません。 代わりに、公式 keyword_search で取れる「このキーワードでのヒット投稿数（＝話題への露出量）」順に並べています。 フォロワー数・閲覧数の欄は「API非対応」と明記しています（スクレイピングは規約違反・アカウント凍結リスクのため不採用）。

検索設定

Threads公式のキーワード検索に渡す語。スペースで複数語も可。
取得方法は最下部の「準備の手順」を参照。デモを見るだけならトークン不要。
ブラウザから graph.threads.net を直接呼べない場合、自分のCloudflare Worker等を経由。空ならプロキシ無しで直叩き。
結果

▎表示している指標の意味

・ヒット投稿数：このキーワード検索で、そのアカウントの投稿が結果に何件現れたか（取得ページ数の範囲内）。露出量の目安。
・最新投稿：結果内でそのアカウントの一番新しい投稿の日時。
・投稿頻度：結果内での最古〜最新のあいだの平均間隔（ヒットが2件以上のとき算出）。
・API非対応：フォロワー数・閲覧数は公式APIで他人分を取得できないため、常に「—」。

▎準備の手順（自分用トークンの取り方）

  1. Meta for Developers でアプリを作成し、Threads API を追加。
  2. 権限（スコープ）に threads_basic と threads_keyword_search を含める。
  3. 自分のThreadsアカウントで認可し、長期アクセストークンを発行。
  4. 上の「アクセストークン」に貼り付けて実行。※keyword_search はアプリ審査/承認が必要な場合があります。

▎安全とプライバシー

・トークンはこの端末（localStorage）にのみ保存され、通信先は Threads API（またはあなたが指定したプロキシ）だけです。
・「記憶」を外せば保存しません。共用端末では記憶しないでください。
・少量・低頻度の利用に留めてください。
