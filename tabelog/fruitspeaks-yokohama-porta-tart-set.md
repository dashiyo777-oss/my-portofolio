# 食べログ原稿：fruits peaks 横浜ポルタ店／タルトセット（一人用）

## タイトル

**昼食はタルト。ナイフとフォークで食べる、横浜ポルタの贅沢セット**

（別案）
- ケーキ屋さんのタルトとは別物。横浜ポルタで「昼食代わりのタルト」
- 一人用タルトセットで、昼からフルーツの贅沢を

## 本文

横浜に用事があった日。せっかくならと、昼食代わりにスイーツを贅沢することにして、横浜ポルタのフルーツピークスに入りました。この日は並ばずに入れて、店員さんの接客も感じがよく、気持ちよく過ごせました。

注文したのは一人用のタルトセット。温州みかんとマスカットのタルト、ハチミツバナナのタルトの2種に、コーヒーが付きます。輪切りのみかんとマスカットが表面を埋めつくす一切れと、たっぷりのクリームにチョコレートを散らした一切れ。見た目から華やかです。

驚いたのはそのボリューム。普通のケーキ屋さんで買うタルトとは一桁違うのでは、と思うほどの迫力で、タルトをナイフとフォークで切り分けて食べたのは初めての経験でした。

デザートではなく、これが昼食。そんな贅沢がしたい日に、ちょうどいいお店だと思います。ごちそうさまでした。
