# note記事：国立大学法人の2025年度決算、赤字12法人はすべて大学病院を持つ

## note貼り付け用（タイトル＋本文）

```
【統覧・官報トピックス】国立大学85法人のうち赤字は12、その12法人すべてが大学病院を持っていた——官報680ページの決算から見えたこと

2026年11月11日｜統覧 — 世界を読み解く視点

官報：2026年10月16日・号外第228号／国立大学法人等85法人の令和7事業年度（2025年度）財務諸表

■ 結論：2025年度の決算で赤字（当期総損失）になった国立大学法人は12。その12法人はすべて附属病院を持ち、病院を持たない44法人に赤字は一つもありませんでした。

10月16日の官報号外は、680ページすべてが国立大学法人の決算でした。北海道大学から情報・システム研究機構まで、85法人の貸借対照表と損益計算書が並んでいます。

統覧は、85法人すべての損益計算書を読み、最後の行の「当期総利益」か「当期総損失」かを確かめました。

■ 1．赤字だった12法人

| 法人 | 当期総損失 | 経常収益（参考） |
| 東京大学 | 約57.3億円 | 約2,998億円 |
| 東京科学大学 | 約55.7億円 | 約1,360億円 |
| 琉球大学 | 約28.3億円 | 約484億円 |
| 大阪大学 | 約25.4億円 | 約1,789億円 |
| 山口大学 | 約12.9億円 | 約574億円 |
| 群馬大学 | 約7.6億円 | 約564億円 |
| 弘前大学 | 約7.4億円 | 約498億円 |
| 滋賀医科大学 | 約6.6億円 | 約377億円 |
| 筑波大学 | 約6.3億円 | 約1,185億円 |
| 佐賀大学 | 約6.0億円 | 約444億円 |
| 山梨大学 | 約3.3億円 | 約478億円 |
| 信州大学 | 約39万円 | 約658億円 |

12法人の赤字を合わせると、約217億円になります。官報の決算書は、法人によって「円」「千円」「百万円」と単位が違うため、すべて億円にそろえて計算しました。

■ 2．病院を持つ41法人と、持たない44法人

85法人を、附属病院を持つかどうかで分けると、次のとおりです。

| 区分 | 法人数 | 赤字の法人 |
| 附属病院を持つ | 41 | 12（約3割） |
| 附属病院を持たない | 44 | 0 |

文部科学省も9月11日の見解で、「12法人の主な赤字の要因は、附属病院の経営状況によるもの」と説明しています。85法人全体では354億円の当期総利益です。全体では黒字なのに、病院を持つ法人だけに赤字が集まっています。

■ 3．なぜ今か：病院の赤字は244億円

国立大学病院長会議が7月に公表した速報では、全国44の国立大学病院の経常損益は、2025年度に合計244億円の赤字でした。赤字だった病院は31です。物価高による医療資材の値上がりと、人件費の上昇が理由に挙げられています。

ここで一つ、数字の食い違いに気づきます。赤字の病院は31あるのに、赤字の法人は12です。病院が赤字でも、大学全体では授業料や研究の収益、過去の積み立ての取り崩しなどで穴を埋め、黒字で終えた法人が多いということです。裏返せば、赤字の12法人は、病院の赤字を大学全体で吸収しきれなかった法人です。

■ 4．見落とされがちな問題：赤字は「お金が足りない」という意味ではない

文部科学省は、損益計算書の赤字は単年度の経営状況を示すもので、現金の出入りとは必ずしも一致せず、資金がショートしていることを表すものではない、と説明しています。赤字は、過去の利益の積み立てや寄附金で手当てされます。

一方で、積み立てを取り崩して赤字を埋める状態が続けば、病院の建て替えや医療機器の更新に回すお金が減っていきます。大学病院は、高度な医療と医師の養成、研究を一体で担っています。その経営の傷みは、地域の医療と次の世代の医師に響きます。

文部科学省は、2025年度補正予算の大学病院への支援（国立大学病院分196億円）と、2026年度の診療報酬改定（約400億円の影響）で、2026年度は改善の見込みだとしています。東京大学については、附属病院以外の部門も赤字で、なお経営努力が必要だとも書いています。

■ 5．誤解の整理

| よくある誤解 | 実際 |
| 国立大学は全体として赤字だ | 85法人全体では354億円の黒字。赤字は12法人 |
| 赤字の大学はお金が尽きている | 損益計算書の赤字は現金不足を意味しない。積立金や寄附金で手当てする |
| 赤字の原因は大学の放漫経営 | 文部科学省は、主な要因を附属病院の経営状況と説明している |

■ 6．統覧の提案

・文部科学省は、法人ごとの決算を、病院部門と病院以外の部門に分けて一覧で公表する。官報の680ページを読まなくても、どこが赤字の原因かわかるようにする
・決算書の単位（円・千円・百万円）を、法人の間でそろえる。比べにくい書き方は、それだけで監視を難しくする
・2026年度の決算で、補正予算と診療報酬改定の効果が出たかを、同じ物差しで検証する

■ 7．結論：国立大学の赤字は、大学の問題である前に、大学病院の問題です。来年の決算で、病院の立て直しが本当に進んだかを確かめる必要があります。
```
