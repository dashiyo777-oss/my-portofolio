## note貼り付け用（タイトル＋本文）

```
【統覧・官報トピックス】国家公務員の遺族補償年金から「夫は60歳以上」の条件が消える——妻が公務で亡くなったとき、夫だけに課されていた壁

2026年11月18日｜統覧 — 世界を読み解く視点

官報：2026年11月18日・号外第251号／国家公務員災害補償法及び国家公務員共済組合法の一部を改正する法律（法律第82号）

■ 結論：2027年4月から、国家公務員が公務や通勤で亡くなったとき、夫が遺族補償年金を受け取るための年齢の条件がなくなります。妻には一度も課されていなかった条件です。

国家公務員が仕事中や通勤中の事故、過労などで亡くなると、残された家族に「遺族補償年金」が支払われます。民間の会社員でいう労災の遺族年金にあたるものです。

この年金には、長く男女の差がありました。夫が亡くなった場合、妻は年齢に関係なく受け取れます。一方、妻が亡くなった場合、夫は原則60歳以上でなければ受け取れませんでした。11月18日の官報に、この差をなくす法律が載りました。

■ 1．新ルールの中身

| 項目 | これまで | 2027年4月から |
| 妻が受け取る条件 | 年齢の条件なし | 変わらず |
| 夫が受け取る条件 | 60歳以上か、一定の障害の状態（55〜59歳は受給資格はあるが、支払いは60歳から） | 年齢の条件なし（妻と同じ） |
| 遺族が1人のときの年金額 | 平均給与額の153日分。55歳以上か障害のある妻だけ175日分 | 一律に175日分 |
| 一部の病気の補償の時効 | 療養補償などは2年 | 判断に時間がかかる病気として人事院規則で定めるものは5年 |

法律は、国家公務員災害補償法の第16条で「妻」と書いていた部分を「配偶者」に改め、夫にだけかかっていた年齢の条件を削りました。国家公務員共済組合法の「公務遺族年金」でも、夫にだけあった年齢の条件を同じように削っています。

年金額も変わります。遺族が1人のとき、これまでは原則153日分で、55歳以上の妻などだけが175日分でした。改正後は、夫か妻か、何歳かにかかわらず175日分になります。

■ 2．なぜ今か：男女の差を消す改正が、制度ごとに続いている

夫だけに年齢の条件を課す仕組みは、国家公務員の制度だけのものではありません。2026年は、この差を消す改正が制度ごとに続いています。

| 制度 | 夫に課されていた条件 | 改正の状況 |
| 民間の労災保険（遺族補償年金） | 55歳以上など | 2026年7月に改正法が成立。2027年度から撤廃 |
| 地方公務員の災害補償 | 60歳以上（当分の間55歳以上）など | 総務省が改正法案を示した。施行は2027年4月の予定 |
| 公害健康被害補償（遺族補償費） | 60歳以上 | 2026年11月13日に改正法が成立 |
| 国家公務員の災害補償 | 60歳以上（当分の間55〜59歳は支払いを停止）など | 11月18日に公布。2027年4月から撤廃 |
| 遺族厚生年金 | 55歳以上 | 2025年の年金制度改正法で、2028年4月から見直し |

もともとこの仕組みは、「夫が働いて妻を養う」という家族の形を前提にしていました。共働きの世帯が多数になったいま、妻の収入で暮らしていた夫が、年齢だけを理由に年金を受け取れない状態は説明がつきにくくなっていました。

この差をめぐっては、地方公務員の遺族が裁判で争い、最高裁は2017年、当時の規定は憲法に違反しないと判断しています。裁判所が違憲としなかった差を、国会が法律で改めた形です。

■ 3．見落とされがちな問題：2027年3月までに亡くなった場合は対象外

法律の附則は、施行日（2027年4月1日）より前に支給の理由が生じた遺族補償年金については、遺族の範囲や年金額について、これまでのルールを使うと定めています。

つまり、2027年3月31日までに妻が公務で亡くなった場合、60歳未満の夫は、改正後も遺族補償年金を受け取れないままです。差が不合理だと認めて改める一方、すでに条件で外れた人を救う仕組みはありません。

■ 4．誤解の整理

| よくある誤解 | 実際 |
| 夫婦どちらが亡くなっても、遺族年金の条件は同じ | 公務の災害補償では、2027年3月まで夫だけに年齢の条件がある |
| 改正されれば、過去に受け取れなかった夫も受け取れる | 施行日より前に亡くなった場合は、これまでのルールのまま |
| 国家公務員だけの話 | 民間の労災、地方公務員、公害補償、遺族厚生年金でも同じ見直しが進んでいる |
| 年金額は変わらない | 遺族が1人のときは、一律に175日分に上がる場合がある |

■ 5．統覧の提案

・人事院は、改正で新たに受給できるようになる夫の数と、175日分への統一で増える支給額の見込みを公表する
・施行日より前に亡くなった職員の夫について、救済の要否を国会で検証する
・共働きの公務員の家庭は、配偶者が公務で亡くなった場合の補償の内容を、2027年4月以降の新しいルールで確かめておく

■ 6．結論：妻が公務で亡くなったとき、夫だけが年齢で外される仕組みは、2027年4月に終わります。ただ、それより前に亡くなった人の家族は、古いルールのまま残されます。
```
