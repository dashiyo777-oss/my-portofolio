# note記事：国保の子どもの均等割5割軽減が18歳未満へ（2027年4月施行）

- 種別: note 記事（統覧・官報トピックス）
- 状態: 下書き（2026-11-11）
- 一次情報: 官報 令和8年11月11日 本紙第1826号（政令第347号、3〜7ページ）、e-Gov 国民健康保険法施行令（2026年8月1日施行版）第29条の7第6項

## note貼り付け用（タイトル＋本文）

```
【統覧・官報トピックス】国保の子どもの保険料、半額になるのは「小学校入学前まで」から「18歳未満」へ——140万人増える軽減と、残る「均等割」という仕組み

2026年11月11日｜統覧 — 世界を読み解く視点

官報：2026年11月11日・本紙第1826号／健康保険法等の一部を改正する法律の施行に伴う関係政令の整備等に関する政令（政令第347号）

■ 結論：2027年度の保険料から、国民健康保険に入っている子どもの「均等割」が半額になる対象は、小学校入学前の子から18歳未満の子に広がります。

国民健康保険（国保）の保険料には、収入に関係なく、加入者一人ひとりにかかる「均等割」があります。生まれたばかりの赤ちゃんにも、高校生にもかかります。

11月11日の官報に、この子どもの均等割を半額にする対象を広げる政令が載りました。自営業やフリーランス、パートなど、会社の健康保険ではなく国保に入っている子育て世帯に関わる改正です。

■ 1．新ルールの中身

| 項目 | いま（2026年度まで） | 2027年度から |
| 半額になる子ども | 小学校入学前（6歳になった後の最初の3月31日まで） | 18歳未満（18歳になった後の最初の3月31日まで、高校生の年代） |
| 軽減の割合 | 均等割の5割 | 変わらず5割 |
| 所得が低く7割軽減を受ける世帯 | 子どもの分は実質8.5割軽減 | 同じ扱いが高校生の年代まで |
| 財源 | 公費（国1/2、都道府県1/4、市町村1/4） | 現行と同様に公費を想定 |
| 申請 | 不要 | 不要 |

官報に載った政令は、国民健康保険法施行令の「世帯に六歳……」を「世帯に十八歳……」に書き換えました。附則で、2027年度分以降の保険料に適用すると定めています。

厚生労働省の資料によると、軽減の対象は約50万人から約180万人に増えます。新たに対象になるのは約140万人です。

■ 2．なぜ今か

未就学児の均等割を半額にする仕組みは、2022年4月に始まりました。厚生労働省は今回の拡大を「子育て世帯の更なる負担軽減のため」と説明しています。根拠になる法律（令和8年法律第31号）は2026年6月に公布され、今回の政令で細かな条文が整いました。

2026年度には、子ども・子育て支援金の分の保険料も国保に加わりました。この分については、18歳未満の均等割がすでに全額軽減されています。今回の政令では、この支援金の分を5割軽減の対象から外しています。二重に軽減しないための整理です。

■ 3．いくら変わるのか

均等割の額は市区町村ごとに違います。例として、東京都葛飾区の2026年度の1人あたりの均等割を見ます。

| 区分 | 1人あたりの均等割（年額） |
| 医療分 | 47,600円 |
| 支援金分 | 17,600円 |
| 合計（子どもにかかる分） | 65,200円 |

この額のまま計算すると、小学生から高校生の子ども1人につき、年に約3万2,600円軽くなります。子どもが2人なら約6万5,200円です。2027年度の実際の額は、その年の保険料率によって変わります。

市の財政に置き換えた例もあります。埼玉県入間市は、2026年度のデータで試算しました。対象は382人（304世帯）から1,651人（1,014世帯）に、軽減額は約943万円から約4,077万円に増えるとしています。

■ 4．見落とされがちな問題：子どもの数だけ保険料が増える仕組みは残る

会社員が入る健康保険には、加入者の数に応じてかかる保険料はありません。扶養する子どもが何人いても、保険料は給料で決まります。国保の均等割は、子どもが増えるほど保険料が上がる仕組みです。

今回の改正で、その負担は半分になります。ただ、残りの半分は残ります。

全国知事会は2025年7月、子どもの均等割の軽減について「18歳までの引上げ及び軽減割合の拡充」を国に提言しました。全国市長会や全国町村会も、同じ趣旨の要望を出しています。今回実現したのは、このうち対象年齢の引き上げだけです。軽減の割合は5割のまま変わっていません。

半額という線で止めたのはなぜなのか。割合を上げる、あるいは全額にするといくらかかるのか。ここは国会の議論や厚生労働省の資料で、引き続き確かめる必要があります。

■ 5．誤解の整理

| よくある誤解 | 実際 |
| 2026年度から安くなる | 適用は2027年度分の保険料から |
| 申請しないと安くならない | 申請は不要。市区町村が保険料を計算するときに軽減する |
| 会社の健康保険に入っている子も対象 | 対象は国民健康保険に入っている子どもだけ |
| 子どもの保険料がゼロになる | 半額になる。子ども・子育て支援金の分は、18歳未満はすでに全額軽減 |

■ 6．統覧の提案

・市区町村は、2027年度の保険料の通知に、子どもの均等割がいくら軽くなったかを分けて書く。軽減が見えなければ、制度の効果も伝わらない
・国は、軽減の割合を上げた場合や全額にした場合の費用を試算し、公表する。5割で止める理由を数字で示す
・国保に入る子育て世帯は、2027年6月ごろに届く保険料の通知で、軽減が反映されているかを確かめる

■ 7．結論：2027年度から、国保の子ども約140万人の均等割が新たに半額になります。子どもの数だけ保険料がかかる仕組みそのものを、次にどうするかが問われます。
```
