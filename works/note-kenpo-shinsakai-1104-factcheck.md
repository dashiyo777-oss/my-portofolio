# note記事：憲法審査会（11/4）で名前が挙がった閣僚8人の裏取り

## note貼り付け用（タイトル＋本文）

```
【統覧・政治家の可視化】憲法審で名前が挙がった閣僚8人、旧統一教会との「接点」を確認できたのは4人——名指しと裏取りの間にあるもの

2026年11月9日｜統覧 — 世界を読み解く視点

■ 結論：名前が挙がった8人のうち、公表された党の調査や本人の説明で接点を確認できたのは4人でした。残る4人は、確認できる資料が見つかっていません。

11月4日の参議院憲法審査会で、いのちの党の奥田ふみよ議員が、改憲の動きと旧統一教会（世界平和統一家庭連合）の関係を取り上げました。その中で、現職の閣僚8人の名前を挙げ、教団とのつながりを調べるよう求めています。

発言の切り抜き動画はSNSで広がりました。ただ、名前が挙がったことと、関係が確かめられていることは別の話です。統覧では、8人それぞれについて、公表された資料で何が言えるかを確かめました。

■ 1．何が起きたのか

報道（ABEMA TIMES、女性自身）によると、奥田議員の主な発言は次のとおりです。

・「困窮する庶民から『早く緊急事態条項を！』という声はない」
・教団の関連政治団体である国際勝共連合の改憲案について「自民党の改憲案と『そっくりだ！』『一致している！』と、よく指摘されている」
・「衆参の憲法審査会会員、幹事、会長を務めるすべての議員の旧統一教会とのつながりを徹底調査することを求めます」

長浜博行会長は「後刻幹事会で検討いたします」と答えました。名前が挙がったのは、次の8人です（肩書は2026年9月の内閣改造後）。

関芳弘 文部科学大臣
井林辰憲 国土交通大臣
古川俊治 デジタル大臣
細野豪志 復興大臣
葉梨康弘 国家公安委員長
山下貴司 法務大臣
笹川博義 環境大臣
中司宏 規制改革担当大臣（日本維新の会）

■ 2．8人を一人ずつ確かめた

| 名前 | 確認できたこと | 根拠 |
| 関芳弘 | 接点あり | 2022年の自民党の点検で「関連団体の会合に本人が出席し、あいさつ」。2026年9月の就任会見で「関係は絶っている」と説明 |
| 井林辰憲 | 接点あり | 2022年の自民党の点検で、同じく「会合に出席し、あいさつ」 |
| 中司宏 | 接点あり | 2022年8月、日本維新の会が接点のある所属議員13人の一人として公表。党は「イベント参加や講演で、組織的な支援や寄付はない」と説明 |
| 葉梨康弘 | 本人が認めた接点 | 2008年ごろ、教団と関係が深いとされる世界日報系の月刊誌にインタビューが載ったと、2022年8月の会見で説明。「取材に応じたからといって、当該団体と関係があるとは認識していない」とも述べた |
| 古川俊治 | 確認できず | 2022年の自民党の公表名簿に名前がなく、報道も見つからなかった |
| 細野豪志 | 確認できず | 同上。2022年当時は自民党の所属ではなく、党の点検の対象外だった可能性がある |
| 山下貴司 | 確認できず | 同上 |
| 笹川博義 | 確認できず | 同上 |

「確認できず」は、関係がないと証明されたという意味ではありません。公表された資料からは、裏付けが取れなかったという意味です。

■ 3．「接点」と「関係」は同じではない

自民党は2022年9月、所属国会議員379人のうち179人に教団側との何らかの接点があったと公表し、そのうち121人の名前を出しました。このうち、選挙で教団側に支援を頼み、組織的な動員を受けたのは2人でした。

確認できた4人の接点は、会合でのあいさつ、イベント参加や講演、雑誌の取材です。会合に一度出たことと、選挙で組織的な支援を受けることでは、重さがまったく違います。名前を一列に並べると、その違いが見えなくなります。

■ 4．見落とされがちな問題

奥田議員の問題提起には、確かめるべき点が含まれています。国際勝共連合が緊急事態条項の新設を求めてきたこと、その改憲案と自民党案の類似は、これまでも報道で指摘されてきました。

一方で、国会の場で閣僚の名前を挙げるなら、一人ずつ何を根拠にしているのかを示す必要があります。根拠が示されないまま名前だけが切り抜かれて広がると、接点が確認された人と、確認できない人が同じように見られてしまいます。

なお、旧統一教会の問題を追及してきた有田芳生衆院議員は、Xで奥田議員の主張に否定的な見方を示しています。緊急事態条項の改憲で国民の財産が教団に渡ることはありえないとし、衆院の憲法審査会で議論されているのは議員任期の延長だと指摘しました。

■ 5．統覧の提案

・国会で特定の議員の名前を挙げて調査を求めるときは、一人ずつ根拠（日付、会合名、出典）を添える
・各党は、2022年の点検以降に新たな接点がないかを改めて点検し、結果を公表する。特に、宗教法人を所管する文部科学大臣や、法務大臣、国家公安委員長は、説明の責任が重い
・SNSで切り抜きを見たら、名前の一覧をそのまま広める前に、一人ずつの根拠を確かめる

■ 6．結論：名指しは調査のきっかけにすぎず、裏取りを経て初めて事実になります。
```
