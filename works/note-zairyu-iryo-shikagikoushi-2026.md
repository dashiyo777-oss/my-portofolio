## note貼り付け用（タイトル＋本文）

```
【統覧・官報トピックス】外国人の歯科技工士と言語聴覚士、日本の免許があっても働けなかった——在留資格「医療」が11月16日から2職種を追加

2026年11月16日｜統覧 — 世界を読み解く視点

官報：2026年11月16日・号外第249号／出入国管理及び難民認定法第七条第一項第二号の基準を定める省令及び出入国管理及び難民認定法施行規則の一部を改正する省令（法務省令第52号）

■ 結論：11月16日から、日本の免許を持つ外国人の歯科技工士と言語聴覚士が、在留資格「医療」で働けるようになりました。働いている歯科技工士の半数以上が50歳以上という中での、受け入れ口の拡大です。

在留資格「医療」は、日本の国家資格を持つ外国人が、医療の仕事をするための在留資格です。医師、看護師、薬剤師、理学療法士など、対象になる職種は法務省令で一つずつ決められています。

その一覧に、これまで歯科技工士と言語聴覚士は入っていませんでした。日本の学校で学び、国家試験に受かって免許を取っても、その仕事でこの在留資格を得ることはできなかったのです。11月16日の官報に載った法務省令は、この2つの職種を一覧に加えました。公布の日から施行されています。

■ 1．新ルールの中身

| 項目 | これまで | 11月16日から |
| 対象の職種 | 医師、歯科医師、薬剤師、保健師、助産師、看護師、准看護師、歯科衛生士、診療放射線技師、理学療法士、作業療法士、視能訓練士、臨床工学技士、義肢装具士 | 左の14職種に、歯科技工士と言語聴覚士を加えた16職種 |
| 受け入れ先（薬剤師などの場合） | 日本の医療機関か薬局 | 医療機関、薬局、その他の保健医療サービスを提供する施設、歯科技工所 |
| 報酬 | 日本人と同じ額以上 | 変わらず |

歯科技工士は、入れ歯や差し歯、かぶせ物などを作る仕事です。言語聴覚士は、話すこと、聞くこと、食べ物を飲み込むことに障害のある人の訓練や支援を担います。

受け入れ先の広がりも見ておく必要があります。歯科技工士の多くは、病院ではなく「歯科技工所」で働いています。これまでの「医療機関か薬局」という条件のままでは、歯科技工士を一覧に加えても、働く場所がほとんどありません。今回の省令は、受け入れ先に歯科技工所と「その他の保健医療サービスを提供する施設」を加えました。この受け入れ先の条件は、薬剤師や理学療法士などにも同じようにかかります。

■ 2．なぜ今か：歯科技工士は10年で3,000人近く減った

厚生労働省の統計で、働いている歯科技工士の数を見ます。

| 年末 | 働いている歯科技工士 |
| 2000年 | 37,244人 |
| 2014年 | 34,495人 |
| 2022年 | 32,942人 |
| 2024年 | 31,733人 |

2024年末は31,733人で、2年前より1,209人（3.7％）減りました。同じ時期に、歯科衛生士は3.0％増えています。

年齢を見ると、もっと厳しい姿が見えます。

| 年齢 | 人数（2024年末） | 割合 |
| 30歳未満 | 3,297人 | 10.4％ |
| 30〜49歳 | 10,677人 | 33.6％ |
| 50〜59歳 | 7,499人 | 23.6％ |
| 60歳以上 | 10,260人 | 32.3％ |

最も多い年齢層は「65歳以上」で、6,127人、全体の19.3％です。50歳以上を合わせると56.0％になります。2000年には、30歳未満の歯科技工士が8,758人いました。2024年は3,297人で、4割以下です。

入れ歯やかぶせ物は、歯科医院の外にある歯科技工所で作られることが多く、歯科技工所も2年で563か所減って20,278か所になりました。作り手が減れば、歯の治療そのものに響きます。

■ 3．見落とされがちな問題：必要なのは「日本の免許」

今回の改正で、外国の歯科技工士がそのまま日本で働けるようになるわけではありません。在留資格「医療」は、日本の法律上の資格を持つ人のためのものです。外国人が歯科技工士として働くには、日本の歯科技工士の免許が必要です。

つまり、最初に恩恵を受けるのは、日本の養成校で学び、日本の国家試験に受かった外国人だと考えられます。そうした人が何人いるのか、毎年どれくらい生まれているのかは、今回調べた公的な資料では確かめられませんでした。改正の効果を測るには、まずこの数字が要ります。

また、医療の国家資格には、今回も一覧に入らなかった職種があります。たとえば臨床検査技師や救急救命士は、16職種に含まれていません。どの職種を加えるかを、どういう基準で決めているのかは、省令からは読み取れません。

■ 4．誤解の整理

| よくある誤解 | 実際 |
| 外国の歯科技工士が日本で働けるようになった | 必要なのは日本の歯科技工士の免許。外国の資格のままでは働けない |
| 医療の国家資格なら、どれでも在留資格「医療」の対象 | 対象は省令で決めた16職種。臨床検査技師や救急救命士は含まれていない |
| 日本人より安い給料で雇える | 日本人と同じ額以上の報酬が条件 |
| 来年から始まる | 11月16日の公布の日から施行 |

■ 5．統覧の提案

・出入国在留管理庁は、今回の2職種で在留資格「医療」を許可した件数を、職種ごとに毎年公表する。改正が担い手不足の解消にどれだけ効いたかを数字で示す
・厚生労働省は、日本の歯科技工士と言語聴覚士の養成校で学ぶ留学生の数と、国家試験に合格した外国人の数を公表する
・国は、在留資格「医療」の対象に加える職種の基準を示す。残された職種を加えるかどうかを、同じ物差しで議論できるようにする

■ 6．結論：歯科技工士の半数以上が50歳を超えるなかで、日本で学んだ外国人が、学んだ仕事で日本に残れる道が開きました。この道を実際に何人が通るのかを、数字で確かめていく必要があります。
```
