## note貼り付け用（タイトル＋本文）

```
【統覧・官報トピックス】刑事裁判のデジタル化、最初は「覚醒剤事件」と首都圏の4地裁から——紙の令状が消える日、何が変わるのか

2026年11月11日｜統覧 — 世界を読み解く視点

官報：2026年10月23日・号外第233号／刑事訴訟規則の一部を改正する規則（最高裁判所規則第13号）、刑事事件等に関する手続において用いる識別符号の付与等に関する規則（同第14号）、最高裁判所告示第9号

■ 結論：刑事裁判のデジタル化は、全国一斉には始まりません。最初は東京・神奈川・埼玉・千葉の裁判所に起訴された覚醒剤の所持と使用の事件だけで、全国のすべての事件に広がるのは2027年7月12日です。

逮捕状や捜索差押許可状は、いまも紙です。警察官が裁判所に紙の請求書を持っていき、裁判官が紙の令状に判を押します。起訴状も、裁判の記録も紙です。

2025年5月に成立した改正刑事訴訟法（令和7年法律第39号）は、これを電子データに切り替えます。10月23日の官報には、その細かな手続を定めた最高裁判所の規則と、どの裁判所のどの事件から始めるかを決めた告示が載りました。号外の約90ページを占めています。

■ 1．何が変わるのか

| 項目 | いま | デジタル化の後 |
| 令状 | 紙で請求し、紙で発付 | 電子データで請求・発付・執行できる |
| 裁判所への申立て | 書面か、書記官の前で口頭 | オンラインで提出できる。口頭の申立ても映像と音声の通話でできる |
| 調書や記録 | 紙で作る | 電子データで作り、ファイルに記録する |
| 証拠の閲覧 | 紙の記録を見る・写す | 電子データの証拠を閲覧・複写する方法を定める |
| 被告人の出廷 | 法廷に来る | 公判期日の手続を、法廷以外の場所からビデオでつないで行えるようにする |

最高裁の規則では、令状をオンラインで請求するときは、本来の管轄の裁判所に加えて、最高裁が定める裁判所の裁判官にも請求できるとしました（刑事訴訟規則第299条第3項を新設）。裁判所のシステムを使うためのID（識別符号）を付ける手続も、別の規則で定めています。

■ 2．なぜ段階的に始めるのか

法律の附則第3条は、施行日の後もしばらくの間、最高裁が定める事件（特定刑事事件）は従来の紙の手続のまま扱うとしています。その範囲は「刑事手続における情報通信技術の活用の段階的かつ円滑な推進に資するため、その範囲が逓減するよう」定めるとされています。紙のまま残す事件を、少しずつ減らしていく仕組みです。

最高裁判所告示第9号は、この特定刑事事件を「次に掲げる事件以外のもの」と定めました。つまり、告示に挙げた事件から新しい仕組みに移ります。時期と裁判所で区切ると、次のとおりです。

| 時期 | 東京・横浜・さいたま・千葉の地裁と家裁、その管内の簡裁 | 大阪・名古屋・広島・福岡・仙台・札幌・函館・旭川・釧路・高松の地裁と家裁、その管内の簡裁 | その他の裁判所 |
| 施行日〜2027年5月9日 | 覚醒剤の所持・使用の事件 | ― | ― |
| 2027年5月10日〜6月13日 | すべての事件 | 覚醒剤の所持・使用の事件 | ― |
| 2027年6月14日〜7月11日 | すべての事件 | すべての事件 | 覚醒剤の所持・使用の事件 |
| 2027年7月12日〜 | すべての事件 | すべての事件 | すべての事件 |

ここでいう覚醒剤の事件は、覚醒剤取締法第41条の2第1項のうち所持の罪と、第41条の3第1項第1号の使用の罪です。

告示は、なぜ覚醒剤事件から始めるのかを書いていません。統覧の読みでは、件数が多く、捜査から起訴までの流れがほぼ決まった事件で、まず新しいシステムを試す形です。首都圏で試し、地域を広げ、最後に全国のすべての事件に切り替えます。紙のまま残す事件は、遅くとも施行日から2年以内に政令で定める日までに、なくなります。

法律の主な部分の施行日は、まだ決まっていません。法律は「令和9年3月31日までの政令で定める日」から施行するとしており、政令で日付が決まると、そこから最初の期間が始まります。

■ 3．最大の疑問：弁護人とのオンライン面会はどうなるのか

裁判所や捜査機関の手続はオンラインになります。一方で、逮捕された人が弁護士とオンラインで話す「オンライン接見」は、今回の法律で権利として定められませんでした。

国会で法務省は、すべての刑事施設で実現できる見通しが立たないまま権利にすると、多くの施設で権利を使えない状態が長く続く、と説明しました。参議院の法務委員会は、必要性の高い地域からできるだけ早く環境を整え、法制化の必要性を施行後3年をめどに検討するよう求める附帯決議を付けています。

捜査する側の手続が速くなるのに、守る側の手段が追いつかなければ、その差は被疑者や被告人の不利益になりかねません。

■ 4．見落とされがちな問題：地域によって、同じ事件でも手続が違う期間がある

2027年5月10日から7月11日までの約2か月、同じ種類の事件でも、どの裁判所に起訴されたかによって、紙の手続と電子の手続が分かれます。

たとえば窃盗事件なら、5月10日以降、東京地裁では電子の手続、大阪地裁では6月14日まで紙の手続です。弁護人や家族にとっては、事件ごとに手続の形を確かめる必要があります。

■ 5．誤解の整理

| よくある誤解 | 実際 |
| 2027年からすべての刑事裁判がオンラインになる | 全国のすべての事件に広がるのは2027年7月12日から。施行日自体もまだ政令で決まっていない |
| 裁判がすべて画面越しになる | 書類の電子化が中心。ビデオでの出廷は、使える場面を広げる規定 |
| 弁護士との面会もオンラインになる | オンライン接見は権利として定められず、環境整備と法制化の検討が附帯決議で求められている段階 |

■ 6．統覧の提案

・法務省と最高裁は、政令で施行日が決まったら、段階ごとの対象（裁判所と事件）を一つの表にして公表する
・最初の覚醒剤事件の期間で起きたシステムのトラブルや手続の遅れを、地域を広げる前に公表する
・オンライン接見は、附帯決議の「施行後3年」を待たず、整備の進み具合を毎年公表する

■ 7．結論：紙の令状がなくなる日は、全国一斉ではなく、首都圏の覚醒剤事件から順にやってきます。その間、守る側の道具が追いつくかどうかも見ていく必要があります。
```
