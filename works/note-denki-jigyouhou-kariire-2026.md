## note貼り付け用（タイトル＋本文）

```
【統覧・官報トピックス】送電網の「借金枠」が1.7兆円から3.9兆円へ、国が進める整備の返済は誰に回るのか——12月2日、改正電気事業法が施行

2026年11月27日｜統覧 — 世界を読み解く視点

官報：2026年11月27日・号外第258号／電気事業法の一部を改正する法律の施行期日を定める政令（政令第362号）、電気事業法の一部を改正する法律の施行に伴う関係政令の整備に関する政令（政令第363号）

■ 結論：12月2日から、送電線や発電所を整えるためにお金を貸す「電力広域的運営推進機関」が借りられるお金の上限が、1兆7,470億円から3兆8,770億円へ、約2.2倍になります。整備を進めるのは国の方針ですが、借りたお金を返していくのは、最後は電気を使う私たちの料金になる可能性があります。

電気は、発電所から送電線を通って家庭や工場に届きます。再生可能エネルギーを増やすにも、データセンターのような大きな需要に応えるにも、送電線と発電所への巨額の投資が必要です。

7月に成立した改正電気事業法は、この投資のお金を国の仕組みで用意できるようにする法律です。11月27日の官報に、施行日を12月2日とする政令と、細かな数字を定める政令が載りました。

■ 1．新ルールの中身

| 項目 | これまで | 12月2日から |
| 電力広域的運営推進機関の借入金と債券の上限 | 1兆7,470億円 | 3兆8,770億円 |
| 機関がお金を貸す相手 | 主に地域と地域を結ぶ送電線（地域間連系線）の整備 | 地域の中の基幹送電線、大規模な発電所の整備にも広げる |
| 卸電力取引所の利益 | 定めなし | 毎年度、国のエネルギー対策特別会計に納める |

電力広域的運営推進機関（広域機関）は、全国の電気の需給を調整するために国の法律でつくられた組織です。改正法では、経済産業大臣が事業者の整備計画を認定し、広域機関がその計画に必要なお金を貸します。

広域機関が貸すお金の元手には、財政投融資などの公的資金が含まれます。参議院の附帯決議も「整備等に必要な資金の貸付け原資には財政投融資等の公的資金を含む」と書いています。

■ 2．なぜ今か

送電網が足りないと、せっかく発電した再生可能エネルギーの電気を送りきれず、発電を止める「出力制御」が起きます。地域と地域の間の送電線が細いと、地域ごとに電気の値段が分かれ、全国で電気を融通しにくくなります。

一方で、送電線や大型の発電所は、建てるまでに10年以上かかり、費用も数千億円単位になります。民間の銀行だけでは貸しにくい長くて大きな投資を、国の仕組みで支えるのが今回の改正の狙いです。

■ 3．最大の疑問：借りたお金は、誰が返すのか

広域機関からお金を借りるのは、送電線を持つ電力会社（一般送配電事業者）や、大規模な発電所を持つ事業者です。借りたお金は、事業者が自分の収入から返します。

送電線を持つ電力会社の主な収入は、送電線の利用料である「託送料金」です。託送料金は、私たちが払う電気料金の中に含まれています。つまり、送電線の整備のために借りたお金は、長い時間をかけて、電気料金の一部として利用者が返していく形になると考えられます。

参議院の附帯決議は、送電網の整備費などが「需要家の過度な負担とならないよう配慮」するよう求めました。附帯決議がわざわざこう書いたこと自体が、負担が利用者に回る可能性を示しています。

■ 4．見落とされがちな問題：もう一つのお金の流れ

今回の政令は、卸電力取引所（JEPX）が出した利益を、毎年度、国のエネルギー対策特別会計に納めるよう定めました。

この利益の多くは、地域と地域の間の送電線が混み合うことで、地域ごとに電気の値段が分かれ、その差から生まれるもの（値差収益）です。附帯決議は、この収益を送電網の整備など安定供給に役立つ事業の財源に充て、使い道を明確にするよう求めています。

送電線が足りないことで生まれたお金を、送電線を増やす財源に回す。考え方は筋が通っています。ただ、特別会計に入ったお金が実際に何に使われたかは、毎年確かめる必要があります。

■ 5．誤解の整理

| よくある誤解 | 実際 |
| 国が税金で送電網をつくる | 国の仕組みで貸すのであって、借りた事業者が返す。返済の元は託送料金などの事業収入 |
| 借入枠が増えた分、すぐに電気代が上がる | 枠は上限。実際にいくら貸すかは、認定される計画しだい |
| 卸電力取引所の利益は取引所のもの | 12月2日以降、毎年度、国の特別会計に納める |
| 再生可能エネルギーのためだけの改正 | 大規模な発電所全般が対象で、原子力も含みうるとの見方もある |

■ 6．統覧の提案

・経済産業省は、認定した整備計画ごとに、貸付けの額、金利、返済の期間、託送料金への影響の見込みを公表する
・広域機関は、3兆8,770億円の枠のうち、どれだけを実際に使ったかを毎年度公表する
・卸電力取引所から特別会計に納めた額と、その使い道を、毎年度並べて公表する

■ 7．結論：送電網の借金枠は2倍以上に広がりました。整備は国の方針でも、返済は電気料金を通じて利用者に回る可能性があります。その中身を、計画ごとに数字で確かめていく必要があります。
```
