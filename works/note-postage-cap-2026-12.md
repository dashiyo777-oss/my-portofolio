## note貼り付け用（タイトル＋本文）

```
【統覧・官報トピックス】手紙の値段の上限「110円」が、12月1日に省令から消える——次の値上げは、誰が、どう決めるのか

2026年11月9日｜統覧 — 世界を読み解く視点

官報：2026年10月30日・号外第238号／郵便法及び民間事業者による信書の送達に関する法律の一部を改正する法律の施行期日を定める政令（政令第341号）、郵便法施行規則等の一部を改正する省令（総務省令第124号）

■ 結論：12月1日から、手紙の料金の上限は国が省令で決めるものではなくなり、日本郵便が申請して総務大臣が認可するものに変わります。

いま25グラムまでの封書は110円です。この110円という上限は、これまで総務省令に数字で書かれていました。10月30日の官報で、その一文を削る省令が公布されました。

大事なのは、値上げが決まったわけではないことです。変わるのは、値上げの「決め方」です。

■ 1．新ルールの中身

| 項目 | これまで | 12月1日から |
| 上限を決めるのは | 国（総務省令） | 日本郵便が申請し、総務大臣が認可 |
| 上限の書き方 | 省令に「百十円」と明記 | 日本郵便が申請書に上限額を書く |
| 変えるとき | 省令を改正する | 新旧の対照と、変える理由を書いて申請 |
| 認可の基準 | ― | 適正な原価を償い、適正な利潤を含む水準を超えないこと |
| 認可の前に | ― | 総務大臣が審議会に諮問する |

官報に載った省令では、郵便法施行規則第23条の「総務省令で定める額は、百十円とする」が削られました。代わりに、日本郵便が上限額の認可を申請するときの書き方が定められています。申請書には上限額を書き、変える場合は新旧の対照と、変える理由を書きます。

改正法は2026年6月に成立しました。総務大臣は、必要と認めれば上限額の変更を命じることもできます。同じ仕組みは、手紙を運ぶ民間の一般信書便事業者にも当てはまります。

■ 2．なぜ今か

郵便の事業は苦しくなっています。総務省の資料によると、郵便事業の営業損益は2022年度に211億円の赤字となり、民営化後で初めての赤字でした。

2024年10月の値上げでは、上限を84円から110円に引き上げるため、省令を改正しました。そのために、審議会への諮問、意見募集（パブリックコメント）、物価問題に関する関係閣僚会議の了承という手続きを踏んでいます。報道によると、今回の改正の狙いは、こうした時間のかかる手続きを経ずに、料金を事業環境に合わせて見直しやすくすることです。

日本郵政は2026年5月の経営計画で、早ければ2027年度中の値上げを目指すとしています。新しい仕組みが動き出すのは、その半年前です。

■ 3．最大の疑問：利用者が意見を言える場は残るのか

これまでの値上げは省令改正だったので、意見募集が行われ、誰でも意見を出せました。認可制に変わると、この手続きがどうなるのか。ここが一番の論点です。

改正後の郵便法の条文を読むと、総務大臣は上限額を認可しようとするとき、審議会に諮問しなければなりません（第73条）。専門家の目を通る仕組みは残ります。

一方で、条文には、認可の前に広く意見募集をすることまでは書かれていません。審議会がこれまでのように意見募集をするかどうかは、運用しだいです。

日本郵便は、郵便事業の収支の状況を総務大臣に報告し、公表しなければならないとも定められています（第67条第9項）。値上げの申請が出たときは、この収支の数字が判断の材料になります。

■ 4．見落とされがちな問題：値上げの幅を左右する650億円

郵政民営化法なども同時に改正され、郵便局網を維持するための新しい交付金が日本郵便に支払われます。日本郵政の社長は2026年6月、交付金は年650億円程度で、値上げ幅が縮まる可能性があると述べました。原資は、政府が持つ日本郵政株の配当などです。

つまり、次の手紙の値段は、日本郵便の申請、総務大臣の認可、そして国のお金の三つで決まることになります。

■ 5．誤解の整理

| よくある誤解 | 実際 |
| 12月1日から値上げされる | 値上げは決まっていない。変わるのは決め方 |
| 国は口を出せなくなる | 総務大臣の認可が必要で、認可の前には審議会に諮る |
| はがきは上限なしで上がる | はがきの料金は、定形郵便物の一番安い料金より低くなければならない（第67条第2項第4号） |

■ 6．統覧の提案

・総務省は、認可の申請があったら、申請書と原価の資料をすぐに公表する
・審議会に諮る際は、意見募集の期間も設ける。省令改正のときと同じように、利用者が意見を出せる場を残す
・交付金がいくら郵便料金の抑制に使われたのかを、毎年わかる形で示す

■ 7．結論：値段の上限を決める場所が、国の省令から認可の手続きに移ります。次の値上げを見るときは、申請書と原価の中身を見る必要があります。
```
