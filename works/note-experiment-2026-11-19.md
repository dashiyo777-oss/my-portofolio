# note 改善実験（2026年11月19日〜25日の7日間）

## 目的

記事の数を増やすことと、読者が増えることは別の問題。読者が実際に何を読んでいるかで判断する。

## ルール（7日間）

1. 朝7時と昼12時の主力記事は維持する
2. 官報記事は、重要度の高い制度変更を優先する（暮らし・お金・権利への影響が大きいもの。細かな手続の改正は見送る）
3. タイトルは「具体的な数字＋制度の矛盾＋国民への影響」で作る
   - 型：`【統覧・官報トピックス】<具体的な数字>、<制度の矛盾>——<国民への影響>`
   - 例：`【統覧・官報トピックス】歯科技工士の56％が50歳以上、日本の免許があっても働けなかった外国人——歯の治療の担い手はどこから来るのか`
4. 公開から24時間後の「閲覧数（ページビュー）」と「スキ率（スキ÷ページビュー）」で比べる
5. 4つの分野で成果を比べる：政治・行政／経済／海外ニュース／よいニュース

## 計測のしかた

- 毎日1回、noteのダッシュボード（記事ごとのページビューとスキ）のスクリーンショットを送ってもらう
- 公開から24時間たった記事について、下の記録表に書き込む
- 分野は、記事の中身で決める（シリーズ名ではなく）。たとえば統覧デイリーでも、国内の政策なら「政治・行政」、市場や物価なら「経済」、外国の話なら「海外ニュース」
- タイトルが新しい型かどうかも記録し、型の効果を見る

## 比べる指標

| 指標 | 計算 |
| 24時間PV | 公開24時間後のページビュー |
| スキ率 | スキ ÷ ページビュー（PVが0の記事は「―」） |
| 分野ごとの中央値 | 記事数が少ないので、平均ではなく中央値で比べる |

### 1．スキは「読まれた量」を表していない
