## 0. この資料の読み方（最初に必ず）

この資料は、事例ごとに次の3つを分けて書いています。

| 区分 | 意味 |
| --- | --- |
| 【確定】 | 判決・公式発表・本人の公の発言など、確認できる事実 |
| 【主張・報道】 | 当事者の主張や週刊誌などの報道で、公式には確認されていないもの |
| 【未確認】 | 本調査では裏取りできなかった点 |

「政治家への忖度で捜査が止まった」という見方は、**どの事例でも裁判所や公的機関が認定したものではありません**。一方で、「捜査機関が違法な捜査をした」「証拠が捏造された可能性が高い」と**裁判所が認めた事例**は実際にあります。この2つを混ぜないことが、この資料のいちばん大事な点です。

なお、元動画の概要欄・字幕は取得できなかったため、動画内の発言は細部まで確認できていません。佐藤誠氏の主張は、同氏の記者会見や週刊文春の報道で確認できる範囲で書いています。

---

## 1. 結論

日本の警察・検察には、次の2種類の問題が実際に確認されています。

1. **政治家が関わる事件で、捜査が途中で止まったり、立件が見送られたりする例が繰り返されている。** ただし「政治的な圧力や忖度があった」と公的に認められた例はなく、警察・検察はいずれも否定しています。疑惑の段階です。
2. **捜査機関が無実の人を罪に陥れた事例は、裁判所が認めている。** 大川原化工機事件（違法捜査で国と都に賠償命令、確定）と袴田事件（再審無罪、証拠の捏造を認定）がその代表です。

共通する根っこは、**捜査を止めた理由・続けた理由が外から検証できない仕組み**（捜査の非公開、第三者検証の不在、個人責任が問われにくいこと）にあります。

| 立場 | 主張 |
| --- | --- |
| 佐藤誠氏（元取調官） | 事件性はあり、捜査は不自然な形で打ち切られた。動画タイトルでは「政治家への忖度」「組織的隠蔽」の可能性を示している |
| 警察庁・警視庁 | 捜査は適正に行われ、証拠上、事件性は認められない |

- 佐藤氏の主張は現場捜査員の経験に基づくもので重みがありますが、**「誰が、いつ、どう指示したか」を示す文書などの証拠は公になっていません。**
- 2023年に「事件性なし」と説明した露木氏は、その後に官房副長官に就いたと報じられています。警察トップが政権の中枢に移ること自体は違法ではありませんが、捜査の中立性への疑問を招く要素ではあります。【報道】

## 4. 裁判所が「捜査機関の違法・捏造」を認めた事例

ここからは疑惑ではなく、判決で確定した事実です。

### 4-1. 大川原化工機事件（冤罪）

| 項目 | 内容 |
| --- | --- |
| 2020年 | 警視庁公安部が、噴霧乾燥器の不正輸出容疑で大川原化工機の社長ら3人を逮捕。東京地検が起訴 |
| 勾留 | 元顧問の相嶋静夫さんは勾留中にがんが見つかり、保釈が認められないまま亡くなった |
| 2021年 | 初公判の直前に検察が起訴を取り消し |
| 2025年5月28日 | 東京高裁が、警視庁公安部と東京地検の捜査・起訴を違法と認定し、国と都に約1億6600万円の賠償を命令 |
| 2025年6月 | 国と都が上告を断念し、判決確定 |
| 2025年8月7日 | 警視庁が検証結果を公表。「捜査指揮系統の機能不全」を認め、退職者を含む19人を処分。警視総監が会見で謝罪。最高検も検証報告を公表 |
| 2026年 | 警察白書が初めてこの事件に触れ、捜査に「多くの問題点があった」と記載 |

残る問題：処分は訓戒や注意が中心で、個人の刑事責任は問われていません。各紙の社説は、なぜ無理な立件に突き進んだのかの動機の解明が不十分だと指摘し、第三者による検証を求める声もあります。

### 4-2. 袴田事件（再審無罪）

| 項目 | 内容 |
| --- | --- |
| 1966年 | 静岡県の一家4人殺害事件で袴田巌さんが逮捕され、のちに死刑が確定 |
| 2024年9月26日 | 静岡地裁が再審で無罪判決。有罪の決め手とされた「5点の衣類」などについて、捜査機関による証拠の捏造を認定 |
| 2024年10月 | 検察が控訴を断念し無罪確定。ただし畝本直美・検事総長は談話で、判決を「到底承服できない」と表明 |
| 2025年9月 | 袴田さんが、検事総長談話で名誉を傷つけられたとして国を提訴。2026年3月の第1回口頭弁論で、国は争う姿勢 |

ポイント：約半世紀にわたり無実の人が死刑囚として扱われ、裁判所が捏造を認めたあとも、検察トップが判決への不満を公に述べた事例です。

## 6. 背景にある制度の問題

| 問題 | 内容 |
| --- | --- |
| 人質司法 | 否認すると長期間勾留され、保釈が認められにくい。ヒューマン・ライツ・ウォッチは2023年の報告書で、日本の「人質司法」が適正手続と公正な裁判を受ける権利を侵害していると結論づけた。大川原化工機事件の相嶋さん、東京五輪汚職事件で約7か月勾留された角川歴彦氏（のちに国賠訴訟を提起）がその例とされる |
| 捜査打ち切りの理由が非公開 | 警察が捜査を縮小・終了しても、その判断過程は外から検証できない |
| 検察の起訴独占と検察審査会の限界 | 不起訴に対して検察審査会が「不起訴不当」と議決しても、強制起訴になるのは「起訴相当」が2回出た場合だけ。再捜査で再び不起訴なら終わる |
| 第三者検証の不在 | 大川原事件でも、検証は警視庁・最高検など当事者自身が行った |
| 個人責任が問われにくい | 違法捜査でも賠償は国や自治体（税金）が払い、担当者個人の責任は国家賠償法上問われない |
| 人事を通じた政治との距離 | 黒川氏の定年延長、警察幹部の官邸への登用などが、中立性への疑念を招いている |

## 7. 統覧の整理（考え方の提案）

1. **「忖度」を証明するのは非常に難しい。** 指示が文書で残ることはまずなく、多くは「なぜ止まったか説明されない」という形でしか表に出ません。だからこそ、疑惑を事実のように語るのではなく、「説明されていないこと」を一つずつ問う姿勢が大事です。
2. **確定した違法捜査から学ぶべきことは多い。** 大川原化工機事件と袴田事件は、捜査機関が「結論ありき」で動くと何が起きるかを、裁判所が認めた形で示しています。
3. **制度で縛る方向が現実的。** 取調べの全面録画、捜査終結理由の記録と事後開示、警察・検察から独立した第三者検証機関、内部告発者を守る仕組みなどは、政治的な立場を問わず議論できる論点です。
