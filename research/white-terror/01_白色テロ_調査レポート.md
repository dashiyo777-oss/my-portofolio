## 結論（要点）

- 「白色テロ」は、**革命側・左派に対して、反革命側・権力側が行う政治的暴力や弾圧**を指す言葉です。フランス革命期（1795年）の王党派の白い花形帽章が語源とされます。[S40][S41]
- 日本語で特に多く使われるのは**台湾の白色テロ**です。1949年の戒厳令から1987年の解除（さらに1992年の刑法第100条改正）までの間、国民党政権が「共産党のスパイ」「反乱」などの名目で、多数の人を軍事法廷で裁き、投獄・処刑しました。[S20][S22][S23]
- 犠牲者の数は**数え方によって大きく違います**。国の「転型正義資料庫」に載る政治受難者は約1万5千人〜2万人台、処刑は「1千人超〜約2千人」という報道があり、百科事典系では「約14万人投獄、3千〜4千人処刑」という推計も流通しています。どの数字も同じ物差しではないので、使うときは出典と数え方を必ず併記すべきです。[S24][S25][S27][S43]
- 台湾は1990年代以降、補償（1998年）、促進転型正義条例（2017年）、有罪判決の撤銷（2018〜2022年で累計5,983件）、国家による賠償（2023年）と、段階的に「移行期正義」を進めています。[S1][S10][S29][S12]

## 1．言葉の意味と由来

| 項目 | 内容 | 出典 |
|---|---|---|
| 基本の意味 | 反革命側・保守側の勢力が、革命派や左派とみなした人々に対して行う暴力・弾圧 | [S44][S45] |
| 対になる言葉 | 赤色テロ（革命側・共産主義側による暴力。ロシアのボリシェヴィキとチェーカーによる弾圧が典型） | [S44] |
| 語源 | フランス革命後の1795年、王党派が帽子につけた**白い花形帽章（コカルド）**から。白はブルボン王家の色 | [S40] |
| フランス（第一次白色テロ） | ロベスピエール失脚（1794年7月）後のテルミドール反動期。ジャコバン派とその支持者が標的で、1795年夏に最大9万人規模の逮捕があったとの記述あり。王党派の主導だったかは議論がある | [S40][S41][S42] |
| ロシア | ロシア内戦（1917〜1923年）で白軍が行った大量殺害を指す用法 | [S45] |
| 台湾 | 国民党政権下の戒厳令期の政治弾圧を指す（以下で詳述） | [S43][S20] |

ポイント：「白」は特定の思想ではなく、**革命を押しとどめる側＝体制側の色**という意味で使われてきました。台湾の場合は「共産主義者の排除」を名目にしつつ、実際には台湾独立派、民主化を求める人、無関係の市民まで巻き込んだ点が特徴です。

## 2．台湾の白色テロの全体像

### 2-1 期間（どこからどこまでか）

| 日付 | 出来事 | 出典 |
|---|---|---|
| 1945年8月15日 | 促進転型正義条例が定める「威権統治時期」の起点 | [S10][S12] |
| 1947年2月28日 | 二・二八事件。台北での衝突から全土に抗議が広がり、武力で鎮圧。犠牲者は約3万人とも | [S50] |
| 1949年5月19日 | 台湾省政府主席・警備総司令の陳誠が「台湾省戒厳令」を公布。翌20日0時から全島で戒厳（公布日と施行日の違いで「5月19日」「5月20日」両方の書き方がある） | [S22] |
| 1960年9月4日 | 雷震事件。雑誌『自由中国』の雷震が、野党結成を試みたとして反乱容疑で逮捕、懲役10年 | [S36][S37] |
| 1979年12月 | 美麗島事件（高雄事件）。指導者らが逮捕され、景美の軍法処で裁判 | [S33][S32] |
| 1980年2月28日 | 林宅血案。美麗島事件で拘束中だった林義雄氏の家族が自宅で殺害された | [S33] |
| 1987年7月15日 | 0時に戒厳令解除（蔣経国総統が7月14日に総統令で公布）。38年間続いた | [S22][S23] |
| 1991年 | 動員戡乱時期臨時条款の廃止（5月1日）、懲治叛乱条例の廃止。独台会事件をきっかけに「100行動連盟」結成（9月21日） | [S16][S17] |
| 1992年5月 | 刑法第100条を改正し、暴力を伴わない言論・主張を内乱罪の対象から外す | [S16][S17][S18] |
| 1992年11月6日 | 金門・馬祖の戒厳解除。促進転型正義条例が定める「威権統治時期」の終点 | [S10][S12] |

注：白色テロの「終わり」は、戒厳令解除の1987年とする見方と、刑法第100条改正の1992年とする見方があります。[S43]

### 2-2 弾圧の仕組み

- **戒厳令**のもと、一般市民でも軍事法廷で裁かれました。[S43][S20]
- 罪名は「反乱」「匪諜（共産党のスパイ）」など。懲治叛乱条例や刑法第100条（内乱罪）が使われ、言論や結社そのものが処罰対象になりました。[S16][S17]
- 当時の最高指導者・蔣介石が直接関与した軍事裁判は**3,195件**にのぼり、下級の判決を3度差し戻して重くしたこともあったと、促進転型正義委員会が資料庫公開時に発表しています。[S24][S25]
- 収容・裁判の主な場所は、台北近郊の**景美（軍法処看守所・法廷）**と、離島の**緑島（政治犯の監獄）**です。現在はどちらも国家人権博物館の園区になっています。[S30][S31][S32]

### 2-3 時期ごとの特徴

| 時期 | 特徴 | 出典 |
|---|---|---|
| 1940年代末〜1950年代 | 共産党員とその同調者の排除が中心。犠牲者の多くはこの時期に処刑・投獄された | [S43] |
| 1960年代〜1970年代 | 雷震事件のように、体制批判・野党結成・台湾独立の動きが標的に | [S36][S37] |
| 1979年〜1980年代 | 美麗島事件、林宅血案など。民主化運動との衝突 | [S33][S32] |

日本では二・二八事件は比較的知られていても、その後の白色テロはあまり知られていない、と日本の研究者も指摘しています。[S52]

| 1999〜2000年 | 補償基金会、1999年度に4,695件受理。2000年度は1,787件の補償に同意、約42億台湾元 | [S2] |

| 2018年 | 国家人権博物館が正式発足（3月設置、5月に開館式。景美・緑島の2園区） | [S30][S31][S32] |

| 2023年8月末 | 権利回復基金会が生命・身体の自由の賠償781件を承認、約22億台湾元。名誉回復証書1,439件 | [S12] |

### 3-2 促進転型正義委員会の5つの任務

1. 政治檔案（公文書）の公開
2. 威権の象徴の撤去と、不義の歴史の現場（遺址）の保存
3. 司法の不正（不当な有罪判決）の是正
4. 歴史の真相の解明と社会の和解
5. 政党が不当に取得した財産の処理（別の委員会と分担）

出典：[S10][S11]

### 3-3 いまも続く論点

- **政治的な対立**：促進転型正義条例の成立時、国民党側は「違憲で人権侵害」と批判し、憲法解釈を求める考えを示しました。白色テロをめぐる議論は、いまも台湾内で対立が強いテーマです。[S47][S43]
- **「真相」と「責任追及」の差**：台湾の調査は、加害者の処罰よりも真相の解明を重視している、という海外メディアの指摘があります。[S48]
- **記憶の多様さ**：本省人・外省人・先住民など立場によって白色テロの記憶は異なり、国家の物語を超えた共通の道徳的基盤が必要だ、とする研究者の論考もあります。[S53]

## 4．誤解しやすい点

| よくある誤解 | 実際 |
|---|---|
| 白色テロ＝二・二八事件 | 二・二八事件（1947年）は白色テロの前段の大事件。白色テロは1949年の戒厳令以降の長期にわたる政治弾圧を指すことが多い |
| 被害者は台湾出身者（本省人）だけ | 資料庫の内訳では外省人も約45%。共産党とのつながりを疑われた中国大陸出身者も多数含まれる |
| 1987年の戒厳解除で終わった | 内乱罪（刑法第100条）による言論処罰は1992年の改正まで残った |
| 犠牲者数は確定している | 数え方と時点で大きく違う。資料庫も「段階的な成果」と位置づけられ、更新が続いている |
